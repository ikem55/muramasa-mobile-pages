# muramasa-mobile-pages

`muramasa-mobile-pages` は GitHub Pages で公開するための静的配信リポジトリです。
このリポジトリ自身でアプリケーションをビルドせず、外部プロジェクトで生成した成果物を配置して公開します。

## 目的

- 当日レース一覧と詳細をスマートフォン向けに表示する
- GitHub Pages で軽量な静的サイトとして配信する
- 配信対象の HTML / JS / CSS / JSON を保管する

## このリポジトリに含まれるもの

- `index.html`
  GitHub Pages から配信されるエントリポイント
- `assets/`
  ビルド済みの JavaScript / CSS
- `data/mobile/`
  画面表示に必要な JSON データ
- `.nojekyll`
  GitHub Pages 用設定

## このリポジトリに含まれないもの

- アプリケーションのソースコード
- ビルド設定
- テスト設定
- データ生成ロジック

これらは外部プロジェクト側で管理します。

## 更新方法

1. 外部プロジェクトで Pages 向け成果物を生成する
2. このリポジトリの `index.html`、`assets/`、`data/mobile/` を更新する
3. 変更内容を確認して main ブランチへ反映する
4. GitHub Pages 上で公開内容を確認する

## 公開運用上の注意

- このリポジトリに置いたファイルは、GitHub Pages と GitHub リポジトリの両方から公開される前提で扱ってください
- API キー、トークン、秘密情報、内部 URL、公開不要な運用情報は置かないでください
- JSON に含める項目は公開前提で選別してください
- 一度コミットした内容は履歴に残るため、削除しても完全に取り消せない場合があります

## 確認ポイント

- `index.html` が最新の `assets/` を参照していること
- `data/mobile/` に不要なファイルが含まれていないこと
- GitHub Pages 上でトップページと詳細ページが正しく表示されること
- 公開してよい情報だけが JSON に含まれていること

## 備考

このリポジトリは配信成果物の保管先です。
実装変更やセキュリティ対策の本体は、生成元の外部プロジェクト側で行ってください。
